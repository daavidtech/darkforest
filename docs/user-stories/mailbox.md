# Mailbox

## View Mailbox

As a player, I can view my mailbox so that I can understand what happened while
time passed.

Acceptance details:

- The mailbox lists reports, alerts, discoveries, intelligence, and player
  messages.
- Each entry shows report type, source, received time, and read status.
- Reports can include location, confidence, last observed time, and action
  links.
- New important reports are visible from the overview.

## Read Report

As a player, I can read a report so that I can act on what my civilization
knows.

Acceptance details:

- Opening a report shows its full contents.
- Reports distinguish confirmed information from estimated information.
- Reports can link to map tiles, buildings, units, technologies, or actions.
- Reading a report marks it as read.
