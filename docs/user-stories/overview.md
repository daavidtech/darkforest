# Overview

## View Civilization Summary

As a player, I can view a summary of my civilization so that I understand what
needs attention.

Acceptance details:

- The overview shows current resources.
- The overview shows population, happiness, and innovation score.
- The overview shows active construction and unit training progress.
- The overview shows recent mailbox reports.
- Warnings are visible for shortages, full storage, incoming attacks, or other
  urgent events.

## See What Finishes Next

As a player, I can see upcoming completions so that I can plan my next action.

Acceptance details:

- The overview lists the next building completion if one exists.
- The overview lists the next unit training completion if one exists.
- The overview lists active research or discovery status if one exists.
- Each item shows remaining real-world time.
