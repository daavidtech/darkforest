# Resources

## View Resource State

As a player, I can view resources so that I know what I can afford.

Acceptance details:

- The resource page shows current stockpiles.
- The resource page shows production rates.
- The resource page shows storage capacity.
- The resource page shows upkeep and consumption.
- Shortages and overflow risks are clearly visible.

## Produce Resources Over Time

As a player, my buildings produce resources over persistent time so that my
civilization continues developing.

Acceptance details:

- Production is calculated from elapsed real-world time.
- Production uses active building effects.
- Production stops or slows when storage is full.
- Upkeep is deducted from production or stockpiles.
- Resource changes are reflected after returning to the game.
