# Units

## Train Unit

As a player, I can train a unit so that I can scout, defend, raid, or perform
specialized work.

Acceptance details:

- The player can view available unit types.
- Unit availability depends on buildings and technology.
- Training consumes required resources and assigns population.
- Training takes real-world time.
- The trained unit appears at the origin building or settlement.
- A unit training report is added to the mailbox.

## View Units

As a player, I can view my units so that I know what forces and specialists I
control.

Acceptance details:

- The units page lists existing units.
- Each unit shows type, location, status, and upkeep.
- Traveling units show destination and remaining travel time.
- Unavailable units cannot be assigned to conflicting actions.
